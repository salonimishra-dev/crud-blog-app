# **Simple CRUD Blog App**

A lightweight blog application built with **Node.js, Express, and EJS**, featuring full **CRUD** functionality.
Deployed online at: [https://blog-pmfp.onrender.com/posts](https://blog-pmfp.onrender.com/posts)

---

## **Features**

* 🌸 Create new blog posts
* 📖 View all posts in a card grid
* ✏️ Edit existing posts
* 🗑️ Delete posts
* 💖 Responsive and clean pink-themed UI
* ✅ Fully functional with dynamic routes

---

## **Live Demo**

Check the live app here: [https://blog-pmfp.onrender.com/posts](https://blog-pmfp.onrender.com/posts)

---

## **Tech Stack**

* **Node.js** – JavaScript runtime
* **Express.js** – Web framework
* **EJS** – Templating engine
* **UUID** – Unique ID generator for posts
* **Method-Override** – Handling PATCH & DELETE HTTP methods
* **CSS** – Responsive styling

## **Installation (Local)**

1. Clone the repository:

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/crud-blog-app.git
```

2. Navigate to the project folder:

```bash
cd crud-blog-app
```

3. Install dependencies:

```bash
npm install
```

4. Start the server:

```bash
npm start
```

5. Open your browser and go to:

```
http://localhost:3000/posts
```

---

## **Usage**

* Go to `/posts` to see all blog posts
* Click **Create New Post** to add a post
* Click **Edit** to update a post
* Click **Delete** to remove a post
* Click **View** to see the full post
